# WallTeen Android — sem anúncios + Premium

Versão 1.1.0 do projeto Android.

## Modelo
- O app **não possui anúncios**.
- O Premium é uma assinatura do Google Play.
- ID do produto: `wallteen_premium_monthly`.
- O preço e os países ficam configurados no Google Play Console.
- Recursos Premium no app: wallpapers exclusivos, downloads HD, criador ilimitado e coleções especiais.

## Antes de publicar
1. Abra o projeto no Android Studio.
2. No Google Play Console, crie uma assinatura com o ID `wallteen_premium_monthly`.
3. Defina preço, período e disponibilidade.
4. Faça um teste interno com contas de teste do Play Console.
5. Gere o AAB assinado e publique.

A integração usa Google Play Billing 9.1.0, versão disponível em junho de 2026. Consulte a documentação oficial para mudanças futuras.
